# rc-aircraft

Drone and RC airplane projects: designs, build notes, flight-controller
configs, and firmware.

Suggested layout as projects come along:

```
<project-name>/
  cad/        source CAD (STEP, FreeCAD, etc.)
  print/      STL/3MF exports
  config/     flight controller / transmitter configs (Betaflight, ArduPilot, EdgeTX)
  notes.md    build log, parts list, wiring
```
